# 蒸馏方法

## 目标

把长篇作品的表达机制转化为可调用、可测试、可迁移的 Agent 指令，而不是保存原文或收集口癖。

这里的蒸馏不是把“请模仿某作者”写进系统提示词。分析从完整长篇文本开始，通过连续切片和统计标注建立证据，再把重复出现且能跨主题迁移的机制变成 Skill。原文只属于分析输入，不属于公开成品，也不参与日常运行。

## 七个阶段

### 1. 整体定位

记录：

- 叙述立场
- 读者关系
- 信息目标
- 语气范围
- 可迁移边界

### 2. 连续切片

覆盖完整文本，按自然段和长度切成连续片段。切片用于分析，不进入公开 Skill。

每个切片只提取：

- 位置区间
- 字数、段落和句子统计
- 主要与次要功能
- 转折、事实、解释、场景、人物压力、幽默和收束等标记计数

### 3. 六路提取

分别提出候选规则：

| 方向 | 关注内容 |
| --- | --- |
| 结构 | 开头、转折、结尾、段落移动 |
| 语气 | 平实、判断、克制、轻幽默 |
| 句法 | 短句、断句、并列和节奏 |
| 翻译 | 抽象概念如何变成普通语言 |
| 人物 | 背景、目标、限制、选择、后果 |
| 故事 | 场景、冲突、因果和局部收束 |

### 4. 三重筛选

候选规则必须同时满足：

1. 重复性：在多个切片中出现；
2. 可迁移性：能用于历史之外的新主题；
3. 非口癖性：不是固定句子、名句或作者专属身份标记。

不满足的规则删除。

### 5. 可执行化

把每条规则写成：

```text
现象 → 为什么有效 → Agent 应做什么 → 什么时候不能用
```

这一步产生的才是 Skill 指令。它不是来源文本的摘要拼接，也不是作者身份提示词。

### 6. 原创测试

使用与原作品无关的新任务测试：

- AI 概念
- 产品价值
- 流程说明
- 人物材料
- 专业报告改写
- 作者模仿边界

测试只使用新写输出，不复用来源文本。

### 7. 公开清理

删除：

- 原文和长段摘录
- 可重建原文的逐切片定位
- 内部业务名称和私有测试材料
- 绝对路径、缓存和压缩包
- 依赖作者身份或固定口癖的说明

保留：

- 聚合统计
- 可迁移规则
- 原创示例
- 测试任务与边界
