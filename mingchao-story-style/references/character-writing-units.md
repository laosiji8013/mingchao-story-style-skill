# Character Writing Units

Use these rules when writing people, founders, operators, users, managers, or historical figures.

## 1. Character-As-Pressure Model

Do not introduce a person as a static biography.

Use:

```text
出身/位置 -> 想要什么 -> 受什么限制 -> 做了什么选择 -> 承担什么后果
```

This converts a person from a name into a force inside the story.

## 2. File-Card Entry

For major characters or products, open with a compact "file-card" inventory.

Include only useful facts:
- role
- background
- key constraint
- main action
- consequence

Do not overuse tables. The point is orientation, not database display.

## 3. Judgment With Evidence

Give a judgment only after the reader knows the relevant pressure.

Good:
```text
他真正难的地方，不是没有选择，而是每个选择都有代价。
```

Bad:
```text
他就是一个伟大的人。
```

## 4. Avoid Unsupported Psychology

Allowed:
- infer motive from action and context
- describe pressure
- describe tradeoff

Avoid:
- claiming private thoughts without evidence
- making villains purely evil
- making heroes purely flawless

## 5. Transfer To Business Writing

For founders:
```text
背景 -> 机会 -> 约束 -> 关键选择 -> 结果
```

For users:
```text
场景 -> 痛点 -> 尝试 -> 阻碍 -> 工具/流程介入 -> 改变
```

For operators:
```text
职责 -> 现场压力 -> 流程动作 -> 风险边界 -> 结果
```
