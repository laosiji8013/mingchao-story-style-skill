# Glossary

> 术语白话转译表。写作前先查这里；表里没有的术语，按「所谓 X，就是普通人熟悉的 Y」现场翻译。
> 翻译要「够用」而非「学术精确」，目标是让非专业读者一眼懂，细节留给需要的人追问。

## 一、AI / 技术域

| 术语 | 白话翻译 |
|---|---|
| 大模型 / 基座模型 | 用海量文本训练出来的通用 AI，是所有 AI 应用的底座。 |
| 多模态 | 不只看文字，也能看图、听声音、理解视频。 |
| Agent | 不是只回答问题，而是能按步骤帮你做事。 |
| 工作流 | 把一件事拆成固定步骤，让人和机器按流程配合。 |
| 上下文窗口 | 模型一次能摊开处理的材料范围。 |
| 上下文长度 | 同上，指一次对话能「记住」多少内容。 |
| Token | 模型算账的最小单位，可以粗略理解成「一个字或一个词」。 |
| 提示词 Prompt | 你给模型下的指令，问得好不好，决定答得好不好。 |
| 微调 | 拿特定材料继续训练，让模型更适应某类任务。 |
| RAG / 检索增强 | 先查资料，再让模型根据资料回答，减少瞎编。 |
| 幻觉 | 模型一本正经地编出一个不存在的事实。 |
| 推理模型 | 回答问题前会先「想一会儿」再答的模型，更擅长难题。 |
| 思维链 | 让模型把思考步骤一步步写出来，答得更靠谱。 |
| 工具调用 | 模型不靠嘴答，而是能去调用别的软件/接口来办事。 |
| 流式输出 | 答案一个字一个字往外蹦，不用等全部生成完。 |
| 模型蒸馏 | 让一个「大老师」把一个「小学生」教成接近自己。 |
| 温度 Temperature | 控制模型「脑洞开多大」的参数，越高越敢编。 |

## 二、产品 / 商业域

| 术语 | 白话翻译 |
|---|---|
| MVP | 先做个最小能用的版本，验证有人要，再投入做大。 |
| 冷启动 | 产品刚上线、一个用户都没有的阶段。 |
| 留存 | 用户今天用了，明天还来不来。 |
| 复购 | 买过一次的人，会不会再买。 |
| 客单价 | 平均一个客户一次花多少钱。 |
| 转化率 | 看了一百个人，最后有几个真掏钱。 |
| 变现 / 商业化 | 把用户或流量变成收入。 |
| 私域 | 你能反复触达、不用再花钱买的用户（群、好友）。 |
| 公域 | 平台上的公共流量，要靠内容或投流去换。 |
| 信息差 | 你知道、别人还不知道的那点东西，往往是生意。 |

## 三、装备 / 流程域（云航）

| 术语 | 白话翻译 |
|---|---|
| 台账 | 一本账，记清楚什么东西在谁手里、状态如何。 |
| 点检 | 按固定项目，一项项检查有没有问题。 |
| 定置管理 | 每样东西有固定位置，用完放回原位。 |
| 责任制 | 每件事明确到人，出事找得到责任人。 |
| 交接 | 把物品、责任、状态说清楚，并留下记录。 |
| 标准化 | 把做事方式固定下来，减少靠个人经验临场发挥。 |

## 四、写作元术语

| 术语 | 白话翻译 |
|---|---|
| 事实材料 | 写作时可以依据的真实信息。 |
| 边界 | 它能解决什么，不能解决什么。 |
| 禁区 | 不能写、不能碰的红线内容。 |

```text
所谓 X，就是普通人熟悉的 Y，只是放在 Z 场景里。
```
