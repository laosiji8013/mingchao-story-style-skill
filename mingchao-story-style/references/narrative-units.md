# Narrative Units

These units come from full-book slice classification and corpus rhythm. They are transferable mechanisms, not copied language.

## 1. Event Staircase

Use a sequence of short steps:

```text
事实出现 -> 压力变大 -> 人物选择 -> 局势转向 -> 结果落下
```

Execution:
- Put one step in one short paragraph.
- Use chronology words only when they change the situation.
- End local sections by naming what changed.

## 2. Reversal Engine

The source relies heavily on turn markers. Transfer this as:

```text
看起来是 X，真正的问题是 Y。
```

Use for:
- Political reversals
- Product limitations
- Process failures
- User misunderstanding
- Strategic misjudgment

Boundary:
- Never create reversal without factual support.

## 3. Case-Walk Narration

The narrator walks the reader through a case, not a textbook.

Execution:
- Start with a concrete file, person, tool, problem, or scene.
- State the stakes.
- Reveal one layer at a time.
- Pause after each important turn.

## 4. Local Closure

Many slices function as small closures, not only final chapter endings.

Execution:
- After a fact cluster, write one sentence that answers "so what?"
- Use closure to help readers carry the point into the next section.
- Avoid slogan endings.

## 5. Explanation Insert

Explanation appears inside narration instead of replacing narration.

Execution:
- Tell what happened.
- Stop briefly to explain why it matters.
- Return to movement.

This keeps the prose from becoming either a dry report or loose storytelling.
