# Input Spec

## Goal

Prepare source slices that are legal, analyzable, annotatable, and transferable into style rules.

## Legal Sources

Use:
- Short excerpts manually provided by the user from a legally obtained copy
- Public preview passages released by the author or publisher
- Short quotations from public promotional pages
- User-written reference passages with a similar target effect
- Authorized source text

Do not use:
- Unauthorized full-book TXT, EPUB, or PDF files
- Pirated downloads
- Large copyrighted passages stored inside the skill package
- A reconstruction of the source book through accumulated excerpts

## Recommended Input Volume

Prepare 20-40 text slices.

For each slice:
- Keep it around 300-800 Chinese characters when possible.
- Mark source location.
- Mark function type.
- Keep only the minimum excerpt needed for analysis.

## Slice Types

| Type | Purpose |
|---|---|
| Opening | Study how a person, issue, or conflict is introduced. |
| Explanation | Study how complex facts become plain language. |
| Turn | Study how contrast, reversal, or tension moves the text forward. |
| Judgment | Study how the narrator gives a clear evaluation. |
| Ending | Study how the passage closes or leaves a hook. |

## Annotation Format

Use this format for each lawful slice:

```markdown
## Slice ID
- Source:
- Type: opening/explanation/turn/judgment/ending
- Length:
- What this slice is doing:
- Main expression method:
- Transferable point:
- Non-transferable point:
- Suitable scenarios for transfer:
```

## Anti-Examples

Prepare 5-10 anti-examples that show what the skill should avoid:
- Too academic
- Too promotional
- Too loose
- Too report-like
- Too motivational
- Too dependent on unexplained jargon
