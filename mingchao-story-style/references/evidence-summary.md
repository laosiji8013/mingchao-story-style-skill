# 切片证据摘要

本文件只保留聚合统计，不包含书籍段落、标题、人物文本或逐切片定位。

这些统计来自对完整长篇文本的切片分析，不是凭少量示例手写一段“仿某作者”的系统提示词。公开 Skill 使用的是统计之后筛选出的可迁移机制。

## 语料概况

- 来源文件约 4.75 MB；
- 估计非空行约 31,614；
- 估计正文段落约 30,893；
- 第二轮连续切片得到 1,831 个分析片段；
- 单片无标点字数中位数约 733；
- 单片段落数中位数约 17；
- 单片句子数中位数约 19。

## 段落和句子

原始段落普遍较短：

| 指标 | 去标点段落字数 |
| --- | ---: |
| 25 分位 | 21 |
| 中位数 | 37 |
| 75 分位 | 57 |
| 平均值 | 42.18 |

句子同样紧凑：

| 指标 | 去标点句子字数 |
| --- | ---: |
| 25 分位 | 18 |
| 中位数 | 31 |
| 75 分位 | 47 |
| 平均值 | 34.96 |

公开 Skill 因此把短段落作为默认，但不机械规定固定字数。

## 功能分布

1,831 个切片的主要功能标签：

| 功能 | 数量 |
| --- | ---: |
| 对话/场景 | 477 |
| 幽默旁白 | 373 |
| 转折 | 372 |
| 叙事 | 170 |
| 判断 | 134 |
| 人物 | 99 |
| 收束 | 93 |
| 解释 | 85 |
| 清单式交代 | 28 |

这说明可读性的主要来源不是单纯“搞笑”，而是场景或对话移动、频繁改变预期、穿插判断，并在局部及时收束。

## 语言标记聚合

分析记录中较高频的标记包括：

- 转折与时间推进
- 对话
- 事实锚点
- 读者关系
- 场景移动
- 幽默旁白
- 人物压力
- 局部收束
- 白话翻译

统计只能说明现象存在，不能直接变成写作命令。公开规则还经过“重复性、可迁移性、非口癖性”三重筛选。

## 推导结果

最终使用的机制公式是：

```text
短段落 + 读者侧旁白 + 事实锚点 + 转折推进 + 白话解释 + 克制幽默 + 明确判断
```

对非历史主题，把历史事实锚点替换成数据、使用场景、流程步骤、产品限制或现场问题。

## 未公开内容

- 书籍原文
- 长段引用
- 真实章节标题
- 段落和行号定位
- 逐切片元数据表

这些内容不是使用 Skill 所必需，也不应通过公开仓库帮助重建来源文本。
