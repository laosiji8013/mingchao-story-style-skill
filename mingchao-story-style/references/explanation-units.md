# Explanation Units

Use these units when the material is abstract, technical, institutional, or easy to misunderstand.

## 1. Translate Before Analyzing

Do not build an argument on an untranslated term.

Internal pattern:

```text
所谓 X，就是普通人熟悉的 Y，只是放在 Z 场景里。
```

Then write it naturally.

## 2. Known-to-Unknown Bridge

Move from what the reader already understands to what they do not.

```text
日常场景 -> 新概念 -> 相似点 -> 不同点 -> 边界
```

## 3. Mechanism In One Breath

For a complex system, explain:
- who/what acts
- what input enters
- what process happens
- what output changes
- where the boundary sits

Keep each item short.

## 4. Fact-Interpretation Pair

Use this rhythm:

```text
事实。
这说明什么。
```

Repeat until the reader has the full picture.

## 5. Misunderstanding Correction

Use when a popular idea is wrong or incomplete:

```text
很多人以为 X。
其实更准确的说法是 Y。
```

Boundary:
- Do not belittle the reader.
- Do not set up fake misunderstandings.
