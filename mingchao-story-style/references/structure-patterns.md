# Structure Patterns

## Default Article Structure

Use this order for most explainers:

1. Fact anchor: name the concrete thing.
2. Judgment: tell the reader what matters.
3. Scene: show where the problem appears.
4. Pressure: explain why the issue becomes difficult.
5. Turn: reveal the contrast or hidden constraint.
6. Explanation: translate the mechanism into ordinary Chinese.
7. Boundary: state what it cannot solve.
8. Closure: answer "so what?"

## Opening Patterns

### File-Card Opening

Use when introducing a person, product, organization, or tool.

Pattern:
```text
先别急着评价它。
我们先看它的基本情况：它是谁，用在哪，解决什么问题，限制在哪里。
```

Then give a short inventory, not a full table unless the user asks for one.

### Result-First Opening

Use when a topic has a surprising outcome.

Pattern:
```text
这件事最后真正改变的，不是 X，而是 Y。
```

Then explain how the result happened.

### Problem-First Opening

Use when the reader already has a practical pain point.

Pattern:
```text
问题不是没人知道要做，而是每个人理解的“做好”都不一样。
```

Then move into scene and mechanism.

### Anti-Jargon Opening

Use for technical topics.

Pattern:
```text
这个词听起来很硬，但它说的其实是一件很普通的事。
```

Then translate the term.

## Section Movement

Use short sections that move like stairs:

```text
事实出现。
问题变大。
有人做选择。
局势发生变化。
真正原因浮出来。
结论落下。
```

For non-history tasks:

```text
场景出现。
痛点变大。
工具/流程介入。
限制暴露。
价值和边界同时落下。
```

## Transition Patterns

Use transitions with different jobs:

| Job | Transition Family |
|---|---|
| Chronology | 于是、后来、终于、从此 |
| Reversal | 然而、不过、可是、但是 |
| Explanation | 其实、事实上、换句话说、也就是说 |
| Problem reveal | 问题是、麻烦在这里、真正难的是 |
| Closure | 所以、到这里、这就说明 |

Do not overuse a single transition. Vary the job, not just the word.

## Ending Patterns

End by closing the practical point:

```text
所以，这套流程真正解决的不是“看起来规范”，而是让责任和下一步动作都变得清楚。
```

Good endings:
- Return to the opening judgment.
- State the boundary.
- Make the reader know what to do next.

Bad endings:
- Empty slogans
- Sudden emotion
- Inflated promises
- Quotes from the source
